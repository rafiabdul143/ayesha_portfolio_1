# Ayesha Jabeen — Portfolio

A modern, responsive React + Vite portfolio based on the information in the supplied resume.

## Included

- Responsive single-page portfolio
- Light/dark theme toggle
- About, Experience, Projects, Skills, Certifications and Contact sections
- View Resume button
- Download Resume button
- The supplied resume PDF is already included at `public/resume/Ayesha_JabeenV.pdf`
- LinkedIn, GitHub and email links
- No referral-message section

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Customize

Most portfolio content is in `src/App.jsx`.
Design, colors, typography and responsive behavior are in `src/styles.css`.
Replace `public/resume/Ayesha_JabeenV.pdf` whenever the resume is updated.
